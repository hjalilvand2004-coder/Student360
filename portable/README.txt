  1) فایل درست را دانلود کرده‌اید؟
     از صفحه Releases گیت‌هاب فقط فایل زیر را دانلود کنید:
        Student360-Portable-Windows.zip   (حدود ۲۸۰ مگابایت)
     فایل «Source code (zip)» نسخه برنامه‌نویسی است و اجرا نمی‌شود!

  2) ابتدا کل ZIP را Extract کنید.
     روی Student360-Portable-Windows.zip راست‌کلیک بزنید و
     «Extract All...» را انتخاب کنید. هرگز فایل bat را از داخل
     خود ZIP اجرا نکنید (در این حالت فقط همان یک فایل در پوشه‌ی
     موقت کپی می‌شود و بقیه فایل‌ها وجود ندارند → خطای
     "The system cannot find the path specified").

  3) بعد از Extract، وارد پوشه‌ی Student360-Portable شوید و
     آن‌جا روی start_student360.bat دوبار کلیک کنید.

  4) پوشه را در مسیر معمولی نگه دارید (دسکتاپ یا D:\)،
     نه داخل Program Files. اگر ویندوز فایروال پیغام داد، Allow بزنید.

سامانه هوشمند برنامه‌ریزی درسی — Student360 (نسخه پرتیبل ویندوز)

★ روش اجرا (بدون نیاز به نصب پایتون یا PyCharm):
   1. روی فایل  start_student360.bat  دوبار کلیک کنید.
   2. چند لحظه صبر کنید؛ مرورگر به‌صورت خودکار روی آدرس زیر باز می‌شود:
        http://127.0.0.1:8000
   3. اگر مرورگر خودکار باز نشد، خودتان کروم یا فایرفاکس را باز کنید
      و آدرس  http://127.0.0.1:8000  را وارد کنید.

★ نکات مهم:
   - هیچ نصبی لازم نیست؛ همه‌چیز (پایتون + کتابخانه‌ها + فرانت‌اند) داخل همین پوشه است.
   - پنجره سیاه (کنسول) نباید بسته شود؛ تا وقتی باز است برنامه کار می‌کند.
     برای خروج، پنجره را ببندید یا داخل آن Ctrl+C بزنید.
   - اگر پورت 8000 اشغال باشد، برنامه به‌صورت خودکار از پورت‌های 8001 تا 8020 استفاده
     می‌کند؛ در این صورت آدرس جدید در همان پنجره کنسول نمایش داده می‌شود.
   - دیتابیس شما در مسیر  data\university_scheduler.db  ذخیره می‌شود.
     برای پشتیبان‌گیری، کافی است از این فایل کپی بگیرید.

★ انتقال به کامپیوتر دیگر:
   کافی است کل پوشه Student360-Portable را با فلش روی سیستم دیگر کپی کنید
   و دوباره روی start_student360.bat دوبار کلیک کنید. (فقط ویندوز 64بیتی)

★ عیب‌یابی:
   - خطای «The system cannot find the path specified» یا «فایل‌های بسته کامل نیست»:
     یعنی فایل‌ها کامل Extract نشده‌اند. بند ۲ بالای همین صفحه را انجام دهید.
   - اگر پنجره باز شده و سریع بسته می‌شود، از داخل CMD این دستورها را اجرا کنید
     تا پیغام خطا را ببینید:
        cd مسیرِ پوشه
        runtime\python.exe app\launch_portable.py
   - خطای «Port not free»: برنامه‌ای که پورت 8000 را گرفته ببندید.
